## android-emu для Windows x64

Новая версия на **C# и WinForms**. Движок — QEMU, без Android Studio или AVD.

- **Android:** выберите локальный установочный x86/x86_64 ISO с поддержкой Legacy BIOS, установите систему в QEMU и сохраните её на отдельном виртуальном диске QCOW2. Последующие запуски идут с диска без ISO.
- **Приложения:** установка и запуск APK через ADB. Проверка ARM64/ARM32 по ABI APK и запущенного Android. Для ARM нужен образ с активным Native Bridge; сами libndk/libhoudini не поставляются.
- **Настройки:** RAM, число ядер, пути к QEMU и ADB, режим автоматического ускорения или TCG.
- **Диагностика:** статус WHPX, проверка ABI гостя, журналы и включение Windows Hypervisor Platform через UAC без автоматической перезагрузки.

Для запуска нужны Windows 10/11 x64, .NET Framework 4.8/4.8.1 и QEMU. Для установки APK нужны также Android SDK Platform-Tools и ADB в гостевой системе. См. [инструкцию](https://github.com/gladok1123/android-emu/blob/v0.3.0/README.md).
