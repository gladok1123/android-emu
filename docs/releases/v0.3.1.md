## Выбор файла виртуального диска

- **Android → Установить из ISO…**: после выбора ISO укажите папку и имя нового `.qcow2`. Лаунчер подключит его в QEMU как единственный жёсткий диск; ISO будет доступен только для чтения.
- **Android → Создать пустой диск…**: создайте отдельный `.qcow2` нужного размера и скопируйте его путь для ручного подключения в QEMU.
- Путь установленной системы виден в поле **Файл диска для QEMU**. Диски v0.3.0 остаются на прежнем месте и продолжают работать.
- Физические диски и общие папки не подключаются. Существующие файлы не перезаписываются. Уже созданный `.qcow2` остаётся по выбранному пути, даже если прервать установку или не добавлять систему в список.

Для запуска нужны Windows 10/11 x64, .NET Framework 4.8/4.8.1 и QEMU. См. [инструкцию](https://github.com/gladok1123/android-emu/blob/v0.3.1/README.md).
